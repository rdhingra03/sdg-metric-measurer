# sdg-metric-measurer
Automated pipeline for sourcing, organizing, and reporting U.S. SDG metrics using public datasets.

 SDG Metric Measurer

This repository supports a project to identify, source, organize, and report U.S. Sustainable Development Goal metrics using public datasets.

## Project Goals

- Identify public datasets aligned with SDG goals, targets, and indicators
- Build a structured data inventory for 210 SDG-related datasets
- Create an automated pipeline for processing and reporting metrics
- Generate SDG-branded data cards showing metric values, sources, and notes
