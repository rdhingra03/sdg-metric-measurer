# SDG 4.2.2 legacy U.S. data pipeline

## What this pipeline measures

This pipeline reproduces the legacy U.S. implementation of SDG indicator
4.2.2: the percentage of 5-year-olds enrolled in organized learning in
October. Organized learning includes:

- nursery school, preschool, or prekindergarten, whether full day or part day;
- kindergarten, whether full day or part day; and
- first grade or any higher elementary or secondary grade.

The estimate uses a child's age at their last birthday on the date of the
October Current Population Survey interview. It does not assign age based on
the beginning of the school year.

## Why the October CPS is the source

The U.S. Census Bureau's Current Population Survey (CPS) includes a School
Enrollment Supplement each October. It asks enrollment questions for people
age 3 and older and provides person-level survey weights. The archived U.S.
SDG metadata identifies an NCES tabulation of this Census survey as its source.

NCES publishes education statistics based on the October CPS, while the Census
Bureau produces and distributes the underlying public-use microdata used by
this pipeline.

Official source pages:

- Census School Enrollment files: <https://www.census.gov/data/datasets/time-series/demo/cps/cps-supp_cps-repwgt/cps-school-enrollment.html>
- Census CPS Microdata API: <https://www.census.gov/data/developers/data-sets/census-microdata-api/cps.html>
- NCES guide to the October CPS source: <https://nces.ed.gov/programs/coe/sources>

## Required variables

| Variable | Use |
| --- | --- |
| `PRTAGE` | Age at last birthday; the pipeline selects exactly age 5 |
| `PESCH35` | Whether a child age 3–5 is enrolled in nursery school, kindergarten, or elementary school |
| `PECHGRDE` | Grade or level attended; used to confirm that enrolled children are in an organized-learning category |
| `PESEX` | Sex, used to calculate separate male and female values |
| `PWSSWGT` or `PWSUPWGT` | Person-level survey weight |

For enrolled children, valid `PECHGRDE` codes are 1 through 16. Codes 1 and 2
are full- and part-day nursery school, preschool, or prekindergarten; codes 3
and 4 are full- and part-day kindergarten; and codes 5 through 16 represent
grades 1 through 12.

## The weight transition in 2006

The correct weight depends on the year:

- 2000–2005: use the basic CPS final person weight, `PWSSWGT`.
- 2006 onward: use the School Enrollment Supplement weight, `PWSUPWGT`.

The Census technical documentation states that supplement weighting was added
to the School Enrollment file beginning in October 2006. A historical pipeline
must not use one weight name indiscriminately across all years.

## Weighted calculation

For each year, the script selects records where `PRTAGE` is 5 and the required
weight is positive.

```text
numerator   = sum of weights for age-5 records where PESCH35 equals 1
denominator = sum of weights for all valid age-5 records

indicator = 100 × numerator ÷ denominator
```

The script keeps the raw survey-weight sums as integers while calculating the
ratio. This avoids avoidable floating-point rounding. The audit output displays
the weighted numerator and denominator as estimated people, including the four
decimal places implied by the public-use weight fields.

The calculated percentage is written with substantially more precision than
the archived display value. Validation separately rounds it to the number of
decimal places stored for each archived observation.

## API and downloadable-file fallback

The script checks the `CENSUS_API_KEY` environment variable.

- If a key is configured and the year is supported, it first requests the
  required person records from the Census Microdata API.
- It validates the content type, JSON structure, required columns, and person
  rows. An HTML error or maintenance page is rejected as invalid data.
- If the key is absent or the API request fails validation, it downloads the
  official compressed Census public-use microdata file.

The compressed fallback file is held and parsed in memory. It is not
permanently extracted. If neither route can supply a complete requested year,
the run fails with a clear message.

Both output files are prepared only after all requested years have been
retrieved, calculated, and validated. A failed run therefore does not overwrite
previously successful output.

## Historical layout handling

CPS fixed-width field positions can change between years. The script therefore
does not assume that one record layout applies to all historical files.

Each downloadable fallback year has an explicit configuration containing:

- the official Census download URL;
- the compressed file format and internal filename;
- a named, verified fixed-width layout; and
- the historically correct weight variable.

The current fallback configuration covers 2018 through 2024. Official
technical documentation shows that these seven files share the relevant field
positions and a 1,090-character record length. Supporting earlier downloadable
files will require adding their verified layouts. With a configured API key,
the named-variable API path can also be used for supported earlier years.

## Sex disaggregation

The same calculation is repeated for `PESEX = 1` (male) and `PESEX = 2`
(female). The script checks that the male and female weighted counts add back to
the national counts.

National results are written to:

```text
data_processed/sdg_4_2_2.csv
```

Male and female results are written separately to keep the national output
simple:

```text
data_processed/sdg_4_2_2_by_sex.csv
```

The five archived family-income groups are intentionally not implemented yet.
They require separately documented household-income and quintile construction
rules and remain future work.

## Validation against the archive

The script reads the legacy canonical file directly from `sdg-master.zip`
inside `source_materials/SDGs.tar`. It does not extract or modify the archive.

For every overlapping year, it compares the calculated national result with
the archived value at exactly the precision stored in that archived row. It
performs the same comparison for the archived male and female rows. The
terminal report gives:

- overlapping years or sex rows;
- exact matches at archived precision;
- maximum absolute difference; and
- any mismatches.

## Pandemic and sampling caveats

The Census Bureau warns that the COVID-19 pandemic affected 2020 CPS response
and may have made enrollment classification more difficult because schooling
could occur remotely or through other nontraditional arrangements. The 2020
estimate is reproducible, but it should retain that qualification.

The CPS is a sample survey. Only a relatively small number of sampled children
are exactly age 5, so estimates can move from year to year because of sampling
variation. The main person weight reproduces the archived point estimate.
Future work could use Census replicate weights to calculate standard errors and
confidence intervals.

Census 2020 user note: <https://www.census.gov/data/tables/2020/demo/school-enrollment/2020-cps.html>

## How to run the pipeline

From the project root, run the default 2018–2024 pipeline:

```bash
python3 scripts/fetch_sdg_4_2_2.py
```

The script uses only Python's standard library and requires internet access.
To prefer the Census API, configure a Census API key without saving it in the
repository:

```bash
export CENSUS_API_KEY="your-key-here"
python3 scripts/fetch_sdg_4_2_2.py
```

An inclusive year range can be requested explicitly:

```bash
python3 scripts/fetch_sdg_4_2_2.py --start-year 2019 --end-year 2022
```

The downloadable fallback currently supports 2018–2024. A request outside
that range needs a working API path or a newly verified year/layout
configuration.
