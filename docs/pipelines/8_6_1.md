# SDG 8.6.1 legacy U.S. data pipeline

## What this pipeline measures

This pipeline reproduces the legacy U.S. implementation of SDG indicator 8.6.1. It calculates the percentage of the U.S. civilian noninstitutional population ages 16–24 who are both:

- not enrolled in school, and
- not employed, meaning they are either unemployed or not in the labor force.

The input data come from the U.S. Bureau of Labor Statistics (BLS) Current Population Survey.

## BLS source series

The calculation uses three official, not-seasonally-adjusted BLS LABSTAT series:

| Series ID | Meaning |
| --- | --- |
| `LNU00022967` | Population ages 16–24 enrolled in school |
| `LNU00023016` | Population ages 16–24 not enrolled in school |
| `LNU02023016` | Employed population ages 16–24 not enrolled in school |

The population figures are reported in thousands. Because every part of the calculation uses the same unit, the “thousands” scale cancels when the percentage is calculated.

## Calculation

The number of people who are not enrolled and not employed is calculated by subtracting employed, not-enrolled people from all not-enrolled people. The total population ages 16–24 is the enrolled population plus the not-enrolled population.

```text
100 × (not enrolled − employed and not enrolled)
    ÷ (enrolled + not enrolled)
```

Using the BLS series IDs, this is:

```text
100 * (LNU00023016 - LNU02023016)
    / (LNU00022967 + LNU00023016)
```

The final result is rounded to one decimal place, matching the archived SDG data.

## Why the pipeline uses M13

The underlying BLS series contain monthly observations identified as `M01` through `M12`. They also contain an `M13` record, which BLS defines as the official annual average for a monthly series.

School enrollment changes sharply during summer because people on summer vacation may be classified as not enrolled. The pipeline therefore uses only BLS’s `M13` annual averages. It does not select one month and does not calculate its own average from monthly percentages.

## Difference from the current UN indicator

This pipeline is a reproduction of the legacy U.S. proxy, not an exact implementation of the current global SDG definition.

- The legacy U.S. measure covers ages 16–24; the global indicator covers ages 15–24.
- The legacy measure identifies people who are not enrolled in school and not employed.
- The global indicator is the percentage of young people not in employment, education, or training (NEET). “Training” is broader than the school-enrollment concept used by these BLS series.

Pipeline results should retain this qualification wherever they are published.

## How to run it

From the project’s top-level directory, run:

```bash
python3 scripts/fetch_sdg_8_6_1.py
```

The script requires internet access but uses only Python’s standard library. A successful run writes:

```text
data_processed/sdg_8_6_1.csv
```

Each output row contains the year, the three BLS input values, the calculated indicator value, the retrieval method, and the retrieval date.

## API and bulk-data fallback

The script first requests the three series from the BLS Public Data API. It checks that the response is valid JSON, reports success, includes every required series, and contains complete annual observations. This prevents an HTML maintenance page from being mistaken for an empty dataset.

If the API request fails or is invalid, the script streams the official BLS Labor Force Statistics bulk data file and selects the same three series. It reads the large file one line at a time rather than saving or loading the entire file into memory.

The `source_method` column records `api` or `bulk`, so each output identifies how it was retrieved. If both methods fail, the script exits with a clear error. It writes through a temporary file and replaces the output only after retrieval, calculation, and validation have succeeded, so a failed run does not overwrite an earlier successful result.

## Archive validation

The script reads the legacy canonical file directly from `sdg-master.zip` inside `source_materials/SDGs.tar`; it does not extract or modify the archive.

For every year present in both the calculated results and the archived file, it compares values after rounding to one decimal place. The terminal report shows:

- the number of overlapping years,
- the number of exact matches,
- the maximum absolute difference, and
- any years that do not match.

Structural checks also stop the pipeline if a required BLS series is absent, the annual year sets do not match, or an annual observation is missing.
