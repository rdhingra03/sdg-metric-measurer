# SDG 15.a.1 and 15.b.1 biodiversity-ODA pipeline

## What this pipeline measures

SDG indicators 15.a.1 and 15.b.1 are repeat indicators in the current UN
framework. Their official definition includes two components. This pipeline
currently measures component (a): official development assistance (ODA) for
the conservation and sustainable use of biodiversity.

For the United States, the result represents the United States **as an aid
donor**, not as a recipient. It is the annual sum of bilateral-allocable ODA
commitments for developing countries where biodiversity is marked as either a
principal or significant objective.

The pipeline does not yet measure component (b), finance mobilized from
biodiversity-relevant economic instruments. The standardized output carries a
warning so this limitation is visible to later users.

## Official source and exact data selection

The primary source is the Organisation for Economic Co-operation and
Development (OECD) Rio Markers / Creditor Reporting System data, retrieved
through the official OECD SDMX service. The pipeline uses dataflow
`OECD.DCD.FSD,DSD_RIOMRKR@DF_RIOMARKERS`, version `1.6`, with these filters:

| Dimension | Selected code | Meaning |
|---|---:|---|
| Donor | `USA` | United States |
| Recipient | `DPGC` | Developing countries |
| Sector | `1000` | All sectors |
| Measure | `100` | Official development assistance |
| Allocable | `2` | Bilateral allocable |
| Marker | `10` | Biodiversity |
| Score | `1` and `2` | Significant and principal objectives |
| Flow | `C` | Commitments |
| Price | `Q` | Constant prices |
| Base period | `2024` | Constant 2024 dollars |
| Drilldown | `_T` | Total |
| Currency | `USD` | U.S. dollars |

OECD reports these observations in millions of dollars. The exact URL used is
saved in every standardized and audit row.

## Calculation

The calculation is intentionally simple:

```text
biodiversity-related ODA = principal amount + significant amount
```

The full value of both scores is used. The pipeline does not apply a 40%
coefficient, include score zero, or add other Rio markers. Principal and
significant amounts are retained separately in the audit file, and the sum is
kept at the precision supplied by OECD.

If OECD omits one score because its annual aggregate is zero, the pipeline
records that score as zero and prints a warning. If both required scores are
missing for a year, the run fails rather than inventing an observation.

## Why this differs from the legacy archive

The legacy U.S. files contain gross disbursements in current U.S. dollars. The
current OECD/UN donor series uses commitments in constant 2024 U.S. dollars.
These are different statistical concepts, so the current output intentionally
does not reproduce the archived values.

The script still reads the canonical archived 2006–2022 values and prints a
year-by-year comparison. This is labelled a **methodology-break diagnostic**,
not a failed validation. The archived files remain untouched.

The methodology variant stored in the standardized output is
`us_donor_biodiversity_oda_commitments`, and its validation status is
`current_methodology_verified` rather than `archive_matched`.

## Twin outputs and audit trail

One source retrieval and one transformation produce:

- `data_processed/standardized/sdg_15_a_1.csv`
- `data_processed/standardized/sdg_15_b_1.csv`
- `data_processed/audit/sdg_15_a_1_15_b_1_inputs.csv`

The two standardized files have identical years and statistical values. Their
indicator IDs keep them as separate SDG outputs. The audit file shows the
principal, significant, and combined amount together with the source filters
and retrieval provenance.

All three CSVs are completely prepared as temporary files before any existing
output is replaced. A retrieval, validation, calculation, or preparation
failure therefore preserves previously successful outputs.

## Optional UN cross-check

When available, the official UN SDG API series `DC_ODA_BDVDL` for area 840
(United States) is used as a secondary check. OECD remains the canonical
source. Identical duplicate UN rows are safely collapsed; conflicting
duplicates are rejected. A temporary UN outage does not fail an otherwise
successful OECD run. Small differences in the newest year may reflect release
timing or revisions and are reported rather than altering the OECD result.

## How to run it

From the project root, run:

```bash
python3 scripts/fetch_sdg_15_a_1_15_b_1.py
```

The command requires internet access to the official OECD service. It prints
the retrieved years, latest principal/significant/combined amounts, optional
UN comparison, and the complete archive methodology-break diagnostic.
